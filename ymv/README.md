# 🎬 YouTube 미디어 다운로더 (동영상 & 음악/오디오 추출)

유튜브(YouTube)에서 **고화질 영상(MP4, MKV)** 또는 **음악/음원(MP3, M4A, FLAC, WAV)**을 손쉽게 다운로드할 수 있는 데스크톱 애플리케이션입니다.

---

## ✨ 주요 기능

1. **🎵 음악 / 오디오 추출 다운로드**
   - 포맷 지원: `MP3`, `M4A`, `FLAC`, `WAV`
   - 음질(비트레이트) 선택: `320 kbps (최고음질)`, `256 kbps`, `192 kbps`, `128 kbps`
   - **앨범 아트(썸네일) 및 가수/제목 태그(ID3 Tag) 자동 삽입** 지원

2. **🎬 동영상 다운로드**
   - 화질 선택: `최고 화질 (원본)`, `4K (2160p)`, `2K (1440p)`, `1080p FHD`, `720p HD` 등
   - 포맷 지원: `MP4`, `MKV`
   - **자막 자동 포함** (한국어/영어) 및 썸네일 커버 포함 옵션

3. **💡 편리한 사용자 인터페이스 (GUI)**
   - **클립보드 붙여넣기**: URL 복사 후 '붙여넣기' 버튼 한 번으로 입력
   - **영상 정보 미리보기**: 영상 썸네일, 제목, 채널명, 재생 시간 자동 표시
   - **실시간 진행률**: 다운로드 퍼센트(%), 속도(MB/s), 남은 시간(ETA), 용량 실시간 표시
   - **재생목록 지원**: 유튜브 재생목록(Playlist) 일괄 다운로드 지원
   - **저장 위치 설정**: 기본 다운로드 폴더 자동 지정 및 '폴더 열기' 버튼 제공

---

## 🚀 실행 방법

### 방법 1: 바탕화면 바로가기 아이콘 (가장 간편)
바탕화면에 생성된 **`YouTube 다운로더`** 바로가기를 더블 클릭하여 실행합니다.

### 방법 2: 폴더 내 배치 파일 실행
`c:\Users\user\Desktop\ymv\run.bat` 파일을 더블 클릭하여 실행합니다.

### 방법 3: 터미널에서 실행
```bash
python main.py
```

---

## 📁 프로젝트 파일 구성

- **`main.py`**: 사용자 그래픽 인터페이스 (CustomTkinter 기반)
- **`downloader.py`**: yt-dlp 및 FFmpeg 기반 영상/음악 다운로드 및 변환 핵심 엔진
- **`run.bat`**: 콘솔 창 없이 깔끔하게 프로그램을 실행하는 런처 스크립트
- **`requirements.txt`**: 필수 라이브러리 목록
- **`README.md`**: 프로그램 설명서
